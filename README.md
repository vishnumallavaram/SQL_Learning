# SQL_Learning

A beginner-friendly SQL learning repository for freshers. This repository is designed to help learners understand SQL concepts, practice through exercises, and apply their knowledge in real-world scenarios.

## Repository Structure

- `module-1/01-ddl-concepts.md` - SQL concepts and fundamentals
- `module-1/02-practical-work.md` - Hands-on practical tasks
- `module-1/03-post-practice-scenarios.md` - Real-world scenario-based questions

## Modules

### Module 1: SQL Fundamentals - DDL & DML Basics
This module covers:
- Database and schema basics
- Tables and rows
- Data types
- CREATE DATABASE and CREATE TABLE
- Primary key and foreign key
- Constraints such as NOT NULL, UNIQUE, DEFAULT, and CHECK
- INSERT, UPDATE, and DELETE basics
- ALTER TABLE operations
- DROP vs TRUNCATE vs DELETE
- Temporary tables and cloning

## How to Use This Repository

1. Start with the concepts file for theory.
2. Complete the practical tasks in the practical file.
3. Solve the interview-style scenario questions in the post-practice file.
4. Practice the concepts in your own SQL environment.

## Recommended Tools

Use any SQL environment such as:
- MySQL
- PostgreSQL
- SQL Server
- SQLite

## Learning Path

- Understand the theory
- Practice in a database tool
- Apply logic to small business scenarios
- Review common interview questions
- Repeat with the next modules
